# Поём вместе / שרים ביחד

Караоке-каталог с меню на русском и иврите. English Rock, English Pop, Jazz & Classics и שירים בעברית сохраняют названия на языке музыки.

## Как пользоваться

Выберите категорию, исполнителя или сборник хитов. Кнопка «Петь» открывает караоке на внешнем сайте. Исполнители с небольшими подборками (до 5 песен) собраны в сборниках соответствующих категорий.

Язык меню, избранное и очередь сохраняются только в браузере посетителя. Сервер и учётная запись для использования каталога не нужны.

## Файлы

- `index.html` — страница сайта.
- `app.js` — поиск, категории, очередь и избранное.
- `i18n.js` — русское и ивритское меню.
- `style.css` — оформление и направление справа налево.
- `songs.js` — данные песен и сборников для браузера.
- `catalog.json` — каталог в формате JSON.

Сайт содержит только названия и ссылки, без музыкальных файлов и текстов песен. Доступность караоке зависит от внешних сервисов.

## GitHub Pages

Публикация из ветки `main`, папка `/ (root)`. Сборка и установка зависимостей не требуются. Файл `.nojekyll` отключает обработку Jekyll.
